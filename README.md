# SaddleBench UMA SaddleMotif proposals

These are the cached geometries used by the default four-method UMA benchmark.
Each original method's 500-attempt batch supplies its own converged saddle
templates for that seed. Files contain the resulting SaddleMotif proposals
with only atomic geometry fields. These are unoptimized guesses.
The published UMA reference revision and file digests are in proposals-index.json.
Exact Search source trajectories and internal work files are kept in the lab cache.
